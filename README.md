### Description:
Alzikrayat is a full-stack, custom MVC photo-sharing platform developed using PHP and MySQL. It allows users to upload memories, browse community photos in an aesthetic gallery, interact via comments, and manage their uploaded media safely.

### Technologies:
- Language: PHP 8.x
- Database: MySQL (MariaDB) via XAMPP
- Architecture: Custom 3-Tier MVC Architecture
- Frontend: HTML5, CSS3, Bootstrap 5, FontAwesome
- Database Driver: PHP Data Objects (PDO)

### How to Run:
1. Place the project folder inside your XAMPP directory: `C:/xampp/htdocs/alzikrayat`
2. Start Apache and MySQL from XAMPP Control Panel.
3. Import or create the database `alzikrayat` in phpMyAdmin.
4. Access the application via: `http://localhost/alzikrayat/public/`
